Ejecución en el clúster

Comandos guardados en scripts/02_ejecutar_mapreduce.txt

Hadoop 3.3.x
1 · Carga en HDFS
hdfs dfs -mkdir -p /data/netflix/clean/ hdfs dfs -put -f netflix_clean.csv /data/netflix/clean/ hdfs dfs -ls -h /data/netflix/clean/
2 · Trabajo MapReduce
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-3.3.6.jar \ -D mapreduce.job.reduces=1 \ -files 02_mapper_actores.py,02_reducer_actores.py \ -mapper "python3 02_mapper_actores.py" \ -reducer "python3 02_reducer_actores.py" \ -input /data/netflix/clean/netflix_clean.csv \ -output /data/netflix/results/actores/
3 · Descarga de las partes
hdfs dfs -ls -h /data/netflix/results/actores/ mkdir -p ./partes hdfs dfs -get /data/netflix/results/actores/part-* ./partes/
4 · Consolidado con Pandas
python3 02_exportar_resultado.py \ --partes ./partes \ --salida ../datos/resultados/mapreduce_actores.csv
Evidencias del reto: captura del listado de HDFS con nombre y tamaño del archivo, captura del job finalizado correctamente, y el archivo mapreduce_actores.csv descargable desde este panel.

Reproducción local

Ensayo del mismo algoritmo sin clúster

Para preparar la demostración en un equipo sin Hadoop, el proyecto incluye un simulador que ejecuta el mapper, ordena por clave y ejecuta el reducer, igual que Hadoop Streaming.

python scripts/02_simular_mapreduce_local.py
El simulador no reemplaza la evidencia de HDFS: sirve para ensayar el algoritmo y regenerar mapreduce_actores.csv si fuera necesario.
